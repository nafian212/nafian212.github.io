Cara Memasang Lagu Di Blog Wordpress Menggunakan Videokeman Tanpa Kolom[Rock ‘n Share!]

Dengan memakai jasa Videokeman judul musik MP3 apa saja dapat kita pasang di blog WordPress. Di Videokeman sendiri menyediakan ratusan jenis judul lagu mulai dari lagu Barat sampai dengan lagu Indonesia. Dengan kapasitas file yang relatif kecil, Videokeman tidak terlalu memberatkan blog saat di akses dan loading juga relatif cepat, sehingga musik tidak putus-putus saat diputar.
Sebelum Anda memasang lagu di blog WordPress anda, ada beberapa syarat yang wajib Anda miliki:




  1. Speaker dan komponen lainnya yang berhubungan dengan mengeluarkan suara masih berfungsi dengan baik.

  2. Telinga Anda dan komponen lainnya masih berfungsi dengan baik. :D

  3. Intrnet Download Manager (IDM) masih berfungsi dengan baik.

Setelah syarat diatas sudah Anda penuhi, kini saatnya proses cara pasang lagu di blog WordPress Anda:




  • Silahkan login ke akun WordPress.com Anda.


  • Kemudian pergi ke videokeman.com                                      


  • Pada halaman utama Videokeman, cari lagu yang ingin anda pasang di blog WordPress Anda.                                                                                                 


  • Sebagai contoh, Saya memilih lagu "Sweet Child Of Mine – Guns N' Roses"

  • Copy kode dibawah ini di Widgets WordPress Anda.

  • Kemudian jika anda menggunakan IDM pasti muncul "Download this audio" seperti gambar di bawah                                                                                   

  • Kemudian tekan dan setelah di tekan muncul IDM seperti gambar dibawah, copy URL nya                                                                                                   

  • Kemudian paste kan ke kode diatas yang bertulisan warna biru ISI LAGUNYA DISINI

  • Pada URL tersebut ubah kata "music2" menjadi "dload" tanpa tanda kutip lalu jangan lupa hilangkan tanda & yang berwarna merah pada kode diatas untuk menjalankannya.



Tambahan : Jika ingin lagu lain di luar web videokeman.com, bisa kok. Caranya tinggal ganti URL nya  yang ada di Download File Info IDM. ( ingat syarat harus ada IDM )

Contoh : mau ganti lagu di web bursamp3.wapka.me



Setelah di klik tombol download now, akan muncul gambar di bawah ini



Copy URL nya dan pastekan di tulisan ISI LAGUNYA DISINI di atas

KET : Jika di belakangnya URL ada .mp3 diganti .vkm
