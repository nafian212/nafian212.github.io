Membuat 1000 Folder Dengan Notepad Dalam Sekejap


  • Buka Notepad



  • Kemudian copy-paste kode script berikut :




Kode :


@echo off : top md %random% goto top





  • Masukan kode script di atas kedalam Notepad



  • Setelah itu klik menu "File" pilih "Save As..."



  • Lalu ubah Save as typenya menjadi "All Files"



  • Ketikan nama yang akan disave yang berakhiran ".bat" misalnya (1000 folder.bat) lalu klik Save



  • Selesai

  • Jika file "1000 folder.bat" tadi yang di buat dijalankan, maka akan membuat banyak folder
