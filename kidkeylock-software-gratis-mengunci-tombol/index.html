Kidkeylock, software gratis untuk mengunci tombol Keyboard & Mouse

Ketika kita mempunyai adik atau anak yang masih kecil, biasanya mereka senang bermain dengan keyboard atau mouse komputer. Jika komputer masih aktif, ketika mereka menekan sembarang tombol di keyboard kadang bisa merepotkan, karena bisa saja menghapus data atau membuat proses yang sedang berjalan menjadi bermasalah. Hal ini bisa kita atasi dengan software gratis KidKeyLock.

Program sederhana ini berfungsi untuk mengunci tombol keyboard dan mouse, meskipun tombol keyboard di klik atau di tekan sembarangan, windows tidak akan merespon atau menanggapinya, sehingga sangat bermanfaat jika anak kecil sering bermain dengan keyboard.

Aplikasi untuk windows 2000, Xp, Vista dan windows 7 ini selain ukurannya kecil dan gratis, tersedia juga versi portable. Penggunaannya sangat mudah, setelah dijalankan, maka program akan berada di pojok kanan bawah layar ( system tray) dalam bentuk icon dengan gambar kunci. Untuk mengaktifkan atau mengunci keyboard, tinggal klik saja icon tersebut dan pilih menu yang di inginkan.



Beberapa fitur KidKeyLock antara lain:

  • Tersedia versi portable, sehingga bisa langsung dijalankan tanpa perlu install

  • Kemudahan akses melalui icon tray

  • Mengunci Mouse, mencakup tombol kiri, tengah, kanan, double klik dan scroll yang ada di mouse ( bisa semua atau kita pilih masing-masing tombol)

  • Mengunci tombol keyboard, mencakup tombol Standard (huruf, angka, tanda baca), tombol tambahan ( home, del, ins, dll), dan windows shortcut (alt-tab, tombol windows, dll)


Ketika tombol keyboard di kunci, kita bisa membuka kuncinya melalui klik icon program ini dan pilih menu “Lock no keys”. Jika tombol mouse juga di non aktifkan, maka untuk membukanya kita harus menggunakan kombinasi tombol di keyboard yang bisa kita set sebelumnya melalui menu “setup”. Informasi selengkapnya silahkan mengunjungi website KidKeyLock.



Tersedia versi installer ( kita harus menginstall terlebih dahulu untuk menjalankannya) dan juga versi portable ( dalam zip, kita tinggal buka zip dan extract isinya, kemudian lihat folder bin dan jalankan file kidkeylock.exe). Silahkan dipilih sesuai dengan kebutuhan kita, karena fungsinya sama saja. Seperti telah dijelaskan diatas, program ini bisa dijalankan di windows 2000, Xp, Vista dan windows 7.

Download versi installer KidKeyLock_setup.exe ( 757 KB) atau versi Portable KidKeyLock.zip ( 536 KB)
