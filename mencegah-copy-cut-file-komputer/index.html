Mencegah Copy atau Cut File Dari Komputer ke USB

Sebuah tips untuk mencegah pengambilan data dari komputer anda ke USB (flashdisk, dll) dalam arti seseorang tidak akan bisa mengambil data dari komputer anda untuk dimasukkan ke USB orang tersebut, tetapi anda tetap bisa mengambil data dari flashdisk untuk dimasukkan ke komputer anda.

Berikut langkah-langkahnya :

1. Masuk ke Regedit ( Klik START pilih RUN ketik regedit)

2. Masuk ke HKEY_LOCALMACHINE\SYSTEM\CurrentControlSet\Control\

3. Klik kanan pada folder Control pilih New>Key

4. Beri nama folder baru itu dengan "StorageDevicePolicies" (tanpa tanda kutip)

5. Lalu klik kanan di folder dengan nama "StorageDevicePolicies", lalu pilih New>Dword

6. Beri nama "WriteProtect" (tanpa tanda kutip)

7. Klik 2x Dword dengan nama "WriteProtect" tersebut, lalu ganti Value Data menjadi 1

8. Restart Komputer anda

>>> Untuk mengembalikan seperti semula anda tinggal mengganti Value Data dari key "WriteProtect" menjadi 0

Selamat Mencoba !!!
